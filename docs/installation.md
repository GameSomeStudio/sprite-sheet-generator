# Installation Guide

## Method 1: Blender Extensions
1. Open Blender 3.6+
2. Edit > Preferences > Get Extensions
3. Search "Sprite Sheet Generator"
4. Click Install

## Method 2: Manual Install
1. Download the latest release ZIP
2. Edit > Preferences > Add-ons > Install
3. Select the ZIP file
4. Enable "Sprite Sheet Generator"

## Method 3: From Source
1. Clone this repository
2. Copy to Blender's addons folder
3. Enable in Preferences
